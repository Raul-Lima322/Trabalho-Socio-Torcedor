# Trabalho-Socio-Torcedor
Trabalho para Pim da Unip para o 1º semestre no curso de análise e desenvolvimento de sistemas

---
## Sobre o projeto:

Sistema em Python para gerenciar o programa de sócio-torcedor do Botafogo. Ele permite cadastrar novos torcedores com validações de e-mail e renda, selecionando o plano ideal para cada perfil. Os sócios podem fazer login para pagar a mensalidade e simular a compra de ingressos com desconto. O código conta ainda com uma área restrita para o administrador visualizar relatórios com o total de inscritos e a situação financeira de cada conta.

---
## Para rodar: 

* No Linux/Mac: `python3 PIM.py`

* No Windows: `python PIM.py`
